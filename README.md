# ML Playground 

This is my personal learning project and a public record of my journey into **Machine Learning Engineering**.

I'm not trying to rush through a predefined roadmap. I'm building my knowledge piece by piece — starting with mathematics, learning Python, experimenting with code, and gradually moving toward machine learning.

The goal is simple:

> **Learn by understanding, experimenting, breaking things, and building them again.**

##  What I'm learning

* 🧮 Mathematics for Machine Learning
* 🐍 Python
* 📊 NumPy & scientific computing
* 📈 Data visualization
* 🤖 Machine Learning
* 🧠 Neural Networks
* 🔬 Practical experiments and projects

##  Mathematics

Mathematics is the foundation of this project.

I'm maintaining a separate structured learning map covering the mathematical concepts I encounter while studying ML.

→ `math/`

##  Experiments

This repository is intentionally a playground.

Not everything here is supposed to be polished. Some code exists simply because I wanted to answer a question:

* What does this mathematical formula actually do?
* What happens if I change this parameter?
* How does a matrix transformation work?
* Why does gradient descent converge?
* What does a neural network actually calculate?

The experiments are part of the learning process.
