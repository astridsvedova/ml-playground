# Mathematics for Machine Learning

This section contains the mathematical foundation I'm building for Machine Learning.

I don't want to memorize mathematics just for the sake of memorization.

Instead, I want to understand the concepts deeply enough to recognize them, use them, implement them in Python, and understand why they appear in Machine Learning.

## How I study

I don't intend to complete this map from top to bottom.

When I encounter something I don't understand while working with Python or Machine Learning, I add that missing concept to the map and study it.

For each topic I try to answer:

1. What is it?
2. Why does it work?
3. How can I express it mathematically?
4. Can I implement a small example in Python?
5. Where does it appear in Machine Learning?
